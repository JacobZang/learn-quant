# 期权组合策略

## 期权 + 股票

### 1. 备兑看涨 Covered Call
**构成**：买入股票 + 卖出看涨（价外）期权

- 最大盈利 = 行权价 - 买入股价 + 权利金
- 最大亏损 = 买入股价 - 权利金
- 盈亏平衡 = 买入股价 - 权利金

**场景**：长期持有、短期不预期大涨；增强收益或降低仓位。盈利有上限，亏损有下限。

### 2. 保护性看跌 Protective Put
**构成**：买入股票 + 买入看跌（价内）期权

- 盈亏平衡 = 行权价 + 权利金
- 最大亏损 = 买入股价 - 行权价 + 权利金
- 最大盈利 = 无上限

**场景**：长线持有但短期不确定；重大事件前对冲。亏损有保底，盈利不封顶。期权占用资金一般为股票盈利的 20%。

### 3. 衣领策略 Collar
**构成**：买入股票 + 卖出看涨（价外）+ 买入看跌（价内）

- 最大盈利 = 看涨行权价 - 买入股价 - (买入看跌 - 卖出看涨的成本)
- 最大亏损 = 买入股价 - 看跌行权价 + (买入看跌 - 卖出看涨的成本)

**场景**：股票已有上涨，想保护利润不被侵蚀；愿意放弃进一步上涨换取保护。

## 期权 + 期权

### 4. 跨式策略 Straddle
**构成**：同时买入相同行权价、相同到期日的 Call + Put

- 盈亏平衡 = 行权价 ± 买入 Call 和 Put 的成本

**场景**：重大事件前（财报、经济数据）；预期剧烈波动但方向不确定。**做多波动率**。

### 5. 牛市看涨价差 Bull Call Spread
**构成**：买入低行权价 Call（平价）+ 卖出高行权价 Call（到期日相同）

- 最大盈利 = 高行权价 - 低行权价 - 成本
- 最大亏损 = 成本（有限）

**场景**：温和看涨；控制成本&风险。

### 6. 熊市看跌价差 Bear Put Spread
**构成**：买入高行权价 Put（平价）+ 卖出低行权价 Put（到期日相同）

- 最大盈利 = 高行权价 - 低行权价 - 成本
- 最大亏损 = 成本（有限）

**场景**：温和看跌；控制成本&风险。

## 涡轮/牛熊证注意事项

### 涡轮要素
底层资产、到期日（年月，当月最后一周行权）、行权比例、行权价

### 涡轮套利原理
**卖出贵的，买入便宜的。**

### 选涡轮标准
- 杠杆比率：**10 倍以下**
- 到期日：**6 个月以上**
- 引伸波幅：越低越好（获利空间更大）
- 街货比 + 溢价率：**15% 以内，价内轮**

### 关键提醒
- 期权/涡轮的时间价值下跌非常快，是最大风险
- 闪电打下来的时候，你必须在场
- **不建议做空**
- 对冲基金做的是"市场中性"——既不单边做多，也不单边做空
