# 基本面分析清单

分析一家公司从五个维度打分（风险分 + 定性分 + 定量分），核心是**判断"为什么这么便宜"而非"有多便宜"**。

## 一、利润表

| 指标 | 判断标准 |
|------|---------|
| ROE | 越高越好（银行看 ROA，>1 优秀） |
| 营业收入占比 | 最好占总收入 ≥90% |
| 收现比 | >1，卖东西的钱都收回来了，营收真实 |
| 三年净现比 | <10% 观望；10-70% 观察；≥70% 优秀（重资产&金融类不适用） |
| 营业成本率 | 稳定=正常，小幅降=控成本，大幅增减=不对劲 |
| 毛利率/净利率 | 对比同行，越高越好 |

## 二、负债表（资产 = 负债 + 所有者权益）

| 指标 | 判断标准 |
|------|---------|
| 资产负债率 | >60% 可能资不抵债（金融/地产/重工业不适用） |
| 有息负债率 | 对比同行，越小越强势 |
| 长期资金占不动产比率 | =（所有者权益+非流动负债）/（固定资产+在建工程），<1 说明长期资金覆盖不了设备 |
| 流动比率 | 流动资产/流动负债，2 左右理想，远>2 可能资金闲置 |
| 速动比率 | （流动资产-存货-预付）/流动负债，1 左右理想，<0.5 危险 |

### 轻/重资产判断
- 有形资产比例 =（固定资产+在建工程）/总资产，>30% = 重资产
- 利润总额/有形资产 >10% 的重资产公司，赚钱能力强

## 三、费用

- 费用率（4费/营收）保持稳定，小幅下降=控成本
- 高科技 → 看研发费用；高利润 → 看销售费用；大规模 → 看管理费用
- 消费类：销售费用可能先行，其次营收利润增长（前提产品好）

## 四、运营能力

- 总资产周转率：上升好，下降也可能是薄利多销（配合毛利率/应收/存货/现金流判断）
- 存货周转天：越短越好；存货周转率：越高越好
- 应收账款周转天：越短越好
- 现金循环周期 = 存货周转天 + 应收周转天 − 应付周转天，越小越好，**负值=欠着别人钱，极好（前提有钱）**

## 五、现金流量表

### 经营活动现金流净额
- 正的好；某年负可能是增加研发/销售费用

### 投资活动现金流
- 为正 = 变卖资产/股票；为负 = 对内投资扩大产能
- 购建固定资产...支付的现金 = 对内投资（扩大产能）
- 取得子公司...支付的现金 = 组建/并购子公司
- 投资支付的现金 = 买股权、债券、并购、贷款

### 筹资活动现金流
- 权益性：增发股票（吸收投资） vs 分红（分配股利，越多越好）
- 债务性：借银行（取得借款） vs 偿债（偿还债务）

### 现金流肖像（经营/投资/筹资三组合）
- **+++ 妖精**：上市未满3年正常；上市多年还这样，可能是借壳或转型，警惕
- **+-+ 蛮牛**：想扩张，看项目前景能否持续覆盖
- **+-- 奶牛**：赚到钱，可偿债+分红+扩张；但要看5年经营流入是否持续大于投资+筹资流出
- **++- 老母鸡**：经营+投资+筹资-，要么还债要么分红，看PE低不低、股息率高不高

### 现金等价物
- 期末现金余额 > 有息负债（短期+长期借款+应付债券）

## 六、估值（关键）

- **自由现金流比净利润更衡量是否真赚钱（尤其周期股）**
- 每股现金流：看收入和股价是否匹配
- 卖出估值 ≈ 芝士高估 + 中值/2 × 每股净资产
- 买入在低估左右，参考同行业

## 七、技术指标参考（KDJ）

- K、D 向上交叉 = 买入信号；向下交叉 = 卖出信号
- J 线大幅超过 K、D = 超买/超卖，可能反转
